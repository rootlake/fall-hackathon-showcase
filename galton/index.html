How to use this

  1. Drop one ball. One trial can land in any bin.
  2. Drop 120. The middle should grow tallest.
  3. Compare the green bars with the red marks.
  4. Set a side wind, press Reset, and drop again. The average should move off the dashed line.

Matter.js runs the physics. The bars count where those balls actually stop.
